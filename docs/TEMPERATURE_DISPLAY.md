# Seasonal temperature display

All supported 850-mb and 2-m temperature-anomaly maps use a shared −6°C to +6°C scale in 0.5°C bands, with each boundary labeled. Whole degrees omit trailing decimals. Negative values use blue; near-zero values use white; positive values progress through pale yellow, orange, and red, following the approved 500-mb palette.

The 24 colors align with 25 boundaries. Values outside the scale saturate at the endpoint colors; forecast values and downloaded numerical grids are unchanged. Monthly and seasonal products use the same scale. Existing images acquire the new style when rerendered. The temperature-style-refresh workflow refreshes supported products and publishes successful producer runs.
